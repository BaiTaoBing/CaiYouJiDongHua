配中文旁白、背景音乐、字幕与 HUD。

### 2026-10-19 夜（第二轮反馈）的改动

用户验收不通过后逐条改的五项：

1. **锯齿**：走 composer 时画布 `antialias` 无效、默认 render target 也没有 MSAA。
   现在给 `EffectComposer` 显式传一个 `WebGLRenderTarget({type: HalfFloatType, samples: 4})`
   （WebGL2 MSAA，仍是 1:1 出帧不超采样，`?draft=1` 时 samples=0）。
   **代价：1080p 渲染 2.2 fps → 约 1.8 fps**（101 s 全片 ≈ 30 min，只慢 ~20%）。
   注意：短测（几十帧）会被页面加载/着色器编译的固定开销掩盖，要用页面内自报的
   `N/3030 … fps` 那行读数，别拿墙钟时间算。
2. **气门开启方向**：门头锥面原来做成"上宽下窄"（倒扣的碗），已改为 `cyl(headR*0.78, headR, …)`
   上窄下宽；关闭位是门头**骑在座圈里**（底面在火力面上方 0.15），开启时整组沿 -y 下沉 1.35
   进燃烧室——即真机的 poppet 阀逻辑（凸轮压下弹簧盘、门头沉进去，座孔环缝过流），
   同时弹簧压缩、座圈/法兰内径放大到不切门头。见 `main.js` 第 543–553 行的注释。
3. **manim M1 + 3D 同步**：M1 的曲柄滑块从水平改竖直（`MX=1.70, O=(MX,-2.05), RL=1.00,
   LL=3.33`，r:l = 6:20），曲柄中心/连杆/活塞落在同一条竖直虚线上；`thetaAt()` 增加
   `SYNC_A=31.2 / SYNC_B=37.6` 的匀速 720° 段，与 M1 的 1.2–7.6 s 指针**同窗同角**。
4. **收尾**：`TOTAL` 106 → 101；删掉最后一句字幕（铭牌复述）与第 10 句旁白；
   HUD 95.2–96.6 s 淡出、整屏 97.6–100.2 s 淡黑（`index.html` 新增 `#fade` 黑层）。
5. **音效全删**：`assemble.py` 去掉 SFX 那一路与 `--no-sfx` 开关，只留 9 段旁白 + BGM；
   旁白换成 `03_源文件\narration_gsv_best\n1..n9.wav`（GSV 定稿）。

v1 是「先能看」的版本，已确认的问题：曲柄连杆穿模、中间多了一根贯通柱子、
模型只用盒子拼、没有真材质与光照层次。v2 方案针对这些逐项改造，并把成片扩到约 100 s。

## v2 场景结构（`02_工具\src\`）

| 文件 | 内容 |
|---|---|
| `kinematics.js` | `DIM` 尺寸、`pistonY(θ)`、`lift()`、`PHASE_CN`、`pressureAt()` |
| `art.js` | 材质表 `MAT`、剖面线纹理 `hatchTexture()`、`buildBackdrop()`（渐变+网格地面+尘埃）、`buildLights()`（含缸盖/曲轴箱内部补光） |
| `parts.js` | 每个部件一个 `build*()`，机体与缸盖各有一块 `sectionFace()` 剖切面 |
| `main.js` | 主场景：相机关键帧 `CAM`、爆炸位移 `explodeAmt()`、曲轴两圈（`thetaAt`）与气门联动、外壳渐隐（`softenShell`）、两侧引线标注、HUD 与后期（Bloom + 暗角颗粒） |

场景只暴露四个接口给 playwright：`window.__setup(w,h)` / `window.__frame(i,fps)` / `window.__total` / `window.__ready`。

样片的运动与讲解时序：2.4–8.6 s 曲轴转满 720°（一个工作循环，`easeIO` 起停）；
曲柄销位置 `(0, r·cosθ, r·sinθ)`，连杆大端锁在曲柄销上、轴线指向活塞销
（`setFromUnitVectors`），连杆是真的在摆；进气门 710° 开 / 220° 关、排气门
480° 开 / 730° 关（`lift()`），弹簧随气门压缩；9.4 s 起机体与缸盖的铸件壁渐隐到
20% 不透明度，10.2 s 起爆炸散件，11.8 s 相机拉远到能容纳整个爆炸图。

几何约定（2026-10-18 改，两轮）：机体与缸盖是**四面壁的开口腔，不做剖切面板**——
那层板既挡视线又和活塞/连杆的运动冲突。铸件朝腔内的面用 `MAT.inner` 压暗、
前边缘（+z 面）才是 `MAT.cut` 的暖色剖面线，靠明暗分层读结构。进排气道暂时不做：
做不对就是两根不跟气门配合的假管子（`parts.js` 里有注释留位）。冷却水进/出口做在
机体左右两侧（铜接管座 + 法兰），接的是缸套外侧的水腔。

细节约定（第三轮反馈后）：
- 缸盖底部**不铺整块火力面板**（用户：那块板多余、挡视线）。只放两个 `TorusGeometry`
  气门座圈（r2.41 @x=+3.1 / r2.16 @x=−3.1，管径 0.32，`y = deckY+0.42`）+ 喷油器凸台
  （`cyl r1.5 h0.9`）；喷油器喷嘴伸进燃烧室约 0.5。
  **气门（2026-10-19 夜改）**：门头 `cyl(headR*0.78, headR, 0.85)` 上窄下宽（锥面朝上、宽面朝下）；
  关闭位 `VALVE_Y0 = deckY+0.375`（门头底面在火力面上方 0.15，骑在座圈里）；开启 = 整组沿
  −y 下沉 `valveLift = 1.35`（门头进燃烧室），弹簧同步压到 `1 − lift/springH`（`springH=4.6`）。
  座圈法兰内径取 `headR+0.2`（小于门头半径会在开门时切进去）
- **坑（踩了三次）**：`plateYZ(shape, thickness, xc, mat)` 里 `ExtrudeGeometry` 的厚度占
  `x∈[0,T]`，少了 `translate(xc - T/2)` 就会让所有这种零件整体偏 `+T/2`——连杆大端
  "歪在一边、左边有空隙"就是这么来的。现在 `plateYZ` 内部已经减掉 `T/2`
- **坑**：`ExtrudeGeometry` 经 `rotateX(+90°)` 后是**往下长**的，给 y 传值要按"顶面"算
- 曲轴颊板用 `hullTwoCircles([0,0],7.8,[0,R],3.4)` 的**凸包**：配重圆与销座圆之间切线过渡，
  轮廓平滑、既没有凹口也没有拼缝（先试过扇形+臂+销座三块叠，仍能看出缝和凹下去的角）
- 活塞裙部下端**开口**（真实活塞就开口），`MAT.piston` 用 `DoubleSide`；
  销座只做两侧两个小凸台，中间穿销，卡簧铜色
- 大端轴瓦内径 2.0 正好贴住曲柄销、用 `MAT.bush` 铜色；连杆螺栓螺母不画
- **爆炸只拆外壳与飞轮**：头部散件只给 `head`（+11.2）与 `liner`（+6.4）、`fw`（−9.4x）；
  活塞/连杆/曲轴的位移必须是 `[0,0,0]`——它们在几何上是硬链接（连杆两端分别套着
  活塞销和曲柄销），各自散开就会悬在中间、销孔漏空，看着像没装上
- 大端是**一整圈环** `annulusSector(2.42,3.55, 0, 2π)`：分成杆体半环 + 瓦盖半环会在
  分型面留两条直缝，透缝看见铜瓦，会被当成"中间断开"
- 靠镜头那侧（+x）的曲轴颊板用 `MAT.crankGhost`（半透明）：实测它会把曲柄销、铜瓦、
  连杆大端**完全遮死**（把销临时染成绿色渲一帧，画面里一点绿都看不到），
  运转段透明度 0.38、拆解段复原到 0.88
- **相机要装得下整机**：曲轴箱底在 y≈−14、缸盖顶在 y≈45，加字幕条后 1080 画面里
  垂直要留够 60 单位；距离小于约 110 时曲轴会被字幕条切掉——`CAM` 前三个关键帧
  因此定在 `[62,44,104]` / `[56,37,94]` / `[57,36,96]`（看向 y=18）
